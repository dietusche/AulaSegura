AulaSegura

Una app Android offline-first y segura para que los estudiantes de grado 11 consulten sus notas, su horario y los avisos del colegio, incluso sin internet.

Ver repositorio en GitHub Presentación Video de sustentación API JSON

El problema

I.E. Colegio Técnico Francisco de Paula Santander · Villavicencio, Meta

📢 Información dispersa

Notas, horarios y avisos llegan por grupos de mensajería, boletines impresos y plataformas web que no están pensadas para el celular.

📶 Conectividad limitada

Muchos estudiantes tienen pocos datos móviles o señal intermitente y se enteran tarde de su situación académica.

🔐 Datos personales

La información académica está protegida por la Ley 1581 de 2012 y exige controles frente al robo de credenciales y la fuga de datos.

Pregunta problema: ¿De qué manera una aplicación nativa en Android con arquitectura offline-first y controles del OWASP Mobile Top 10 permite a los estudiantes de grado 11 consultar su información académica de forma oportuna, incluso con conectividad limitada, sin exponer sus datos personales?

La solución

Kotlin · Jetpack Compose · Material 3 · Room · DataStore · Android Keystore · GitHub Pages

Inicio

Promedio del periodo, materias en riesgo, estado de sincronización y avisos del colegio.

Notas

Calificaciones por periodo con la escala de desempeño del Decreto 1290 (Superior, Alto, Básico, Bajo).

Horario

Horario semanal por día, con hora y salón.

Sin conexión

Después del primer ingreso, todo se consulta en modo avión desde la base de datos local Room.

Seguridad

Riesgos y controles alineados con el OWASP Mobile Top 10 (2024)

RiesgoOWASPControl implementado
Tráfico interceptado en redes Wi-Fi públicasM5Solo HTTPS/TLS; el tráfico HTTP está bloqueado con Network Security Config
Robo del token o de la claveM1Se compara el hash SHA-256 de la clave; el token se cifra con AES-256-GCM en el Android Keystore y vence a las 8 horas
Exposición de datos localesM9Respaldos y transferencias deshabilitados; solo se guarda lo necesario
